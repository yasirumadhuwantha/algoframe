# Optional local conversation snapshot

The setup inspection found one local Codex JSONL transcript whose filename and session metadata match the active conversation ID and this workspace. Only that matching transcript was inspected; other conversations were not opened.

Run `npm run chat:backup` inside the active agent environment (`npm.cmd run chat:backup` when PowerShell blocks `npm.ps1`). The helper reads `CODEX_THREAD_ID`, or `CODEX_SESSION_ID` if the former is absent, and searches only for filenames ending with that exact UUID under `$CODEX_HOME/sessions` or the default user `.codex/sessions`. It requires a single match and matching session ID/workspace metadata. A normal terminal without the active ID fails explicitly.

Output is `.local/chat-backups/<current-id>.json`. The final anchored `/.local/` rule in `.gitignore` is required. The snapshot contains the conversation ID and text from user messages and completed assistant commentary/final messages in the observed local format. Environment-context messages, system/developer instructions, reasoning, tool messages/results, events, attachments, and other record metadata are excluded. The original transcript is never copied. Credential-like text causes refusal before writing; the helper never prints the text it refused.

This is a local, Git-ignored snapshot, not encryption. Files use owner-only permissions on POSIX; Windows uses the workspace's inherited ACLs. Keep the workspace private. Ignore rules do not remove already tracked files; the security/push review must check the index when a Git checkout is available.

The command reports a message count and destination on success. On missing identity, ambiguous/mismatched transcript, unknown assistant format, malformed/truncated JSON, credential-like content, ignore-rule problems, or filesystem failure it exits nonzero without claiming success or dumping transcript content. Writes replace the previous snapshot atomically only after filtering succeeds. If temporary-file cleanup also fails, the command reports that failure safely; a partial filtered file may remain inside the ignored backup folder for local cleanup. Retry truncated input after the agent has stopped writing.

It is manual: no hook, watcher, scheduler, or automatic backup is installed. A snapshot contains only messages already written when it runs, so it cannot contain the response sent afterward. Attachments are intentionally omitted. The credential detector is conservative pattern matching, not a universal credential recognizer; if a conversation may contain credentials in an unsupported form, do not export it. Future transcript formats require review and tests before support is claimed. Test and live-run results are recorded in [progress](progress.md).
