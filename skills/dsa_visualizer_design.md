# AlgoFrame Visualizer UI Conventions

- Preserve the current neutral/coral/cyan theme introduced on 2026-11-24: near-white pages and panels, charcoal dark surfaces, coral primary controls, cyan statuses, lavender challenges, amber copies, and semantic green completion/error accents. The older cream/sage reference is historical; token names remain for compatibility.
- Keep colors centralized in `src/index.css`: `slate` represents neutrals and `sage` supplies the coral primary ramp. Use the shared `algo-primary`, `algo-selected`, and `play-*` controls plus `--stage-*` / `--diagram-edge*` variables instead of new literal colors in components/SVG.
- Check small labels against their actual pastel or dark surface, not only the page background. Preserve visible keyboard focus, reduced-motion styling, and a header that wraps without page-wide overflow at narrow widths.
- Precision engineering stage: dot-grid canvas (`radial-gradient`) with crisp hairline borders and single-level surface elevation.
- Dual-coded semantic states: always pair color accents with explicit status text labels (`EXECUTING`, `ALLOCATING`, `COMPLETED`, `Retained`, `rewired pointer`).
- Tabular numeric alignment (`tabular-nums` + `JetBrains Mono`) for all memory addresses, indices, byte sizes, and microsecond costs.
- Keep `PythonCodeBox` to the right of the canvas on desktop and below it on narrow screens, synchronized with `step.python_line` and keyboard shortcut `C`. Scroll highlights inside the code panel, without moving the entire page. The first learning frame is function entry; later frames show state after the highlighted operation line.
- Navigation lists the six lecture topics and Graphs, with separate singly/doubly linked lessons. A topic starts with one-click example/empty actions and a collapsed custom setup. Both shortcuts still execute the fixed Python definition; other operations require a successfully initialized structure. Set up remains the first operation, with empty/custom choices.
- Singly linked nodes have value/next compartments; doubly linked nodes have previous/value/next compartments. Display the actual trace references and use local horizontal scrolling for long chains. Graphs use an undirected adjacency-list model and circular vertex markers.
- Keep the single shared playback toolbar and slider in the sticky top header. Sticky sidebar/code offsets follow the measured header height, including mobile wrapping. Controls remain keyboard accessible.
- Let the canvas lead. Keep operation choices compact (locally scrollable on phones), code hidden initially, and variables, memory, custom inputs, and complexity in labeled disclosure controls. Source stays synchronized when revealed.
- Learn automatically animates meaningful trace changes from entry; Explore shows immediate results; Predict locks the cursor until the learner answers or explicitly reveals the animation. Key steps and Python lines share one actual trace cursor. Preserve pause, speed, replay, native slider, and keyboard navigation.
- Animate actual copies, references, traversal focus, stack entry/exit, and circular queue markers. Keep node IDs stable within a trace. Captions explain the current change; diagrams and source remain faithful to post-line snapshots. Honor reduced motion in CSS, Motion, theme transitions, and scrolling.
- Show time complexity, auxiliary/structure space, results, and local variables without presenting modeled memory or execution-line counts as benchmarks. Comparison counts come from real traces. Edge-case experiments explicitly replace the current example.
